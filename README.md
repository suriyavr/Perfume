# 🌸 Perfumy – Perfume Store Website

Welcome to **Perfumy**, a simple and elegant perfume store website built using React.js. This project showcases a collection of perfumes with a clean layout, product search section, navigation bar, About Us section, and Contact section.

## 📌 Project Description

Perfumy is a beginner-friendly React project created to practice component-based development. The website displays perfume products in a row and provides basic sections to help users explore the store.

## ✨ Features

- 🏠 **Navigation Bar** – Home, Products, About, and Contact links.
- 🔍 **Search Bar** – A search input for finding perfumes.
- 🧴 **Product Display** – Displays perfume images and product names.
- ℹ️ **About Us Section** – Introduces the perfume store.
- 📞 **Contact Section** – Displays contact information.
- 🧩 **Reusable React Components** – The website is divided into separate components for easier maintenance.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- React.js
- Node.js and npm

## 🚀 How to Run the Project

Follow these steps to run Perfumy on your local computer.

### 1. Clone the repository

```bash
git clone https://github.com/suriyavr/Perfume.git
```

### 2. Open the project folder

```bash
cd perfumy
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm start
```

Open `http://localhost:3000` in your browser to view the website.
